# Тренер

Локальный агент-тренер по шоссейному велоспорту. Сам берёт данные из Intervals.icu (тренировки, восстановление WHOOP, календарь) и прогноз Open-Meteo, помнит разговоры и факты об атлете.

## Установка

```bash
cd trainer
python3 -m pip install -r requirements.txt
cp .env.example .env
```

Открой `.env` и впиши ключи: `INTERVALS_API_KEY` (из старого `proxy.py` или Intervals.icu → Settings → Developer Settings) и `ANTHROPIC_API_KEY`.

## Запуск

```bash
python3 app.py
```

Открой http://localhost:8765. Старый `proxy.py` больше не нужен — останови его, чтобы не было конфликта порта.

## Что умеет

- **Утренний брифинг** — кнопка в левой панели. Тренер смотрит восстановление за ночь, план на сегодня, нагрузку последних дней и погоду в месте тренировки и начинает ответ с вердикта: по плану, облегчить, станок, перенести или отдых. Один брифинг на день: повторное нажатие открывает уже готовый.
- **План** — хранится локально. Тренер составляет и переставляет тренировки в чате, в панели «План» видно расписание и статусы.
- **Сверка плана с фактом** — выполнено, частично, пропущено, что сделано сверх плана. Статусы обновляются сами.
- **Разбор недели** — объём и нагрузка по неделям, распределение интенсивности, аэробный дрейф на длинных, лучшие усилия и оценка FTP, тренд формы, выводы на следующую неделю.
- **Ощущения после заезда** — блок «Последний заезд» в левой панели: RPE и самочувствие. Для тренировок из Strava, у которых нет данных, можно вписать длительность и пульс. То же можно просто рассказать тренеру в чате.
- **Погода и места** — прогноз на время тренировки и управление местами.

Чтобы брифинг сам смотрел погоду, задай в «Обо мне» обычное место и время старта (или указывай их у тренировок в плане).

## Первые шаги

1. Сохрани места тренировок в «Погода и места» и укажи обычное место и время в «Обо мне».
2. Попроси тренера составить план: кнопка в панели «План» или словами, например «составь план на две недели, 6 часов в неделю, длинная в субботу».
3. Утром жми «Утренний брифинг», после заезда оценивай его в блоке «Последний заезд», в конце недели — «Разбор недели».

Всё, что тренер знает о тебе, видно и редактируется в разделе «Что тренер обо мне знает».

## Как устроено

| Файл | Что делает |
|---|---|
| `app.py` | веб-сервер: чат со стримингом, диалоги, память |
| `agent.py` | цикл Claude с инструментами, сборка контекста, сжатие истории |
| `tools.py` | инструменты тренера: тренировки, восстановление, календарь, погода, память |
| `intervals.py` | клиент Intervals.icu |
| `weather.py` | прогноз и поиск мест Open-Meteo |
| `storage.py` | SQLite в `data/coach.db` |
| `prompts/coach.md` | характер и правила тренера — правь без изменения кода |
| `prompts/plan.md` | тренировочный план |

Память работает в три слоя: весь диалог хранится в базе; когда он становится длинным, старая часть сворачивается в резюме; устойчивые факты (FTP, вес, места, травмы) тренер записывает в профиль и заметки, и они доступны во всех диалогах.

## Доступ с телефона

В `.env` поставь `HOST=0.0.0.0`, перезапусти и открой с телефона `http://<IP-компьютера>:8765`. Пароля нет, поэтому только в домашней сети.

## Модель

По умолчанию `claude-sonnet-5`. Если ключ её не поддерживает, поменяй `MODEL` в `.env`, например на `claude-sonnet-4-5`.

## Ограничения

Активности, пришедшие в Intervals.icu из Strava, API не отдаёт. Тренер это видит и попросит описать такую тренировку словами.
